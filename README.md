# NAJJUBTYPE prototype v2

포스타입 모바일 피드 문법 + 명대사/명장면 아카이브 구조를 결합한 정적 프로토타입입니다.

## 포함 기능
- 명대사/명장면 등록
- 추천순 / 최신순
- 추천, 댓글, 저장, 공유
- 로컬 등록글 수정/삭제
- 1:1 선택을 통한 전체 순위 소트
- 반응/작성 데이터 localStorage 저장

## Vercel
이 폴더 전체를 GitHub 저장소 루트에 업로드한 뒤 Vercel에서 Import하면 됩니다. 빌드 명령은 필요 없습니다.

## 주의
현재는 프로토타입이라 모든 사용자 간 데이터 공유 DB는 없습니다. 실제 공개 서비스에서는 Supabase/Firebase/Postgres 등의 백엔드 연결이 필요합니다.
